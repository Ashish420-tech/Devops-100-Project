# 🚀 Project 29: Uptime Monitoring with Blackbox Exporter

## 📌 Overview

This project demonstrates how to monitor external endpoints using Prometheus Blackbox Exporter.

## 🛠 Tech Stack

* Prometheus
* Blackbox Exporter
* Grafana
* AlertManager

## 🎯 Goal

Monitor uptime, SSL expiry, and TCP connectivity of services.
